物联网（IoT）平台是连接物理设备与业务应用的中间层：向下通过标准协议完成设备接入与数据采集，向上提供设备管理、数据存储、规则计算与可视化分析能力，让分散在不同现场的设备数据汇聚成可运营的数字资产。

平台适用于设备分布广、协议不统一、需要统一监控与预警的场景，如智能工厂、能源管理、智慧园区、环保与安全监测等。它既可以作为独立平台交付，也可以作为 MES、ERP、数字孪生等系统的数据底座。

我们提供的物联网平台支持公有云与私有化部署，具备开放 API 与二次开发能力，可平滑对接企业既有信息化系统，并支持信创环境。
